# Week 3 Logistics EDA Project
This is a hypothetical educational dataset (120 simulated shipments), not real company data.
## Run on Windows
Open PowerShell in this folder:
```powershell
python -m pip install -r requirements.txt
python analyze_logistics.py
```
Files: `logistics_hypothetical_data.csv` is the input; `analyze_logistics.py` calculates descriptive statistics, KPIs, grouped performance summaries, correlations, and six charts. Results are saved to `outputs/` and `visualizations/`.
